# Liam performance standard

The approved reference is **Maybe the Knob Isn't Broken**, render run `29606656473`.

New Liam narration must use a deliberate emotional arc rather than one-note delivery:

- Include clear highs and quiet lows across the full script.
- Vary intensity, pacing, pauses, emphasis, warmth, tension, and intimacy by scene.
- Use laughter only when the writing contains a genuine comedic beat.
- Keep neutral scenes so expressive moments retain contrast.
- Preserve the approved spoken script exactly.
- Store every performance direction only in `audio_tags`.
- Never show performance tags in captions, titles, subtitles, or other visible graphics.

## Opening delivery

The first scene must match the mood and message of that specific script. It may begin with laughter, a low voice, thoughtful reflection, sarcasm, curiosity, excitement, drama, mischievousness, a whisper, or neutral delivery.

Do not default every script to a whisper, curious tone, or any other single opening style. Use laughter only when the opening contains a genuine joke. Use whispers only when intimacy, secrecy, or quiet wonder supports them. Use a low voice when gravity or mystery supports it. A plain opener may remain neutral.

A newly generated performance must equal or exceed the approved reference for naturalness, realism, emotional range, pacing, selective humor, mood-appropriate opening delivery, and scene-to-scene variation. Flat, robotic, forced, repetitive, or constantly exaggerated delivery fails the standard.
